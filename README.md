# Roadmap Python
Mapeamento do meu progresso em Python. Aqui organizo os marcos de aprendizado, desde a sintaxe inicial e estruturas de dados até códigos mais complexos.
Status atual: Finalizando recursos intermediários da linguagem e explorando Orientação a Objetos.

## 🗺️ O Mapa de Aprendizado

/cursopybasico (100% concluído) - O básico da linguagem

Fundamentos — print, str, int, float, bool e coerção de tipos
Variáveis — declaração e exercícios práticos
Operadores aritméticos — cálculos, precedência e IMC
Formatação de strings — f-strings, format, %, fatiamento, split/join/strip
Condicionais — input, if/elif/else, operadores relacionais
Operadores lógicos — and, or, not, in, not in
Boas práticas e conceitos internos — try/except, constantes, flags, is/None, id
Laço while — break, continue, laços internos, calculadora, debugger
Laço for — range, iteradores, jogo da palavra secreta
Listas e tuplas — list, tuple, enumerate, empacotamento, listas aninhadas
Tópicos avançados + Projeto CPF — ponto flutuante, operação ternária, gerador de CPF

/cursopyintermed (60% concluído) - Recursos Intermediários

Funções — definição com def, argumentos, escopo, return, *args, closures e higher order functions
Dicionários (dict) — criação, manipulação, métodos, shallow/deep copy
Conjuntos (set) — introdução, peculiaridades, métodos e operadores
Funções avançadas — lambda, *args, **kwargs e desempacotamento
Comprehensions — list, dict e set comprehension com map e filter
Conceitos internos — isinstance, truthy/falsy, dir/hasattr, iteradores, generators e yield
Tratamento avançado de exceções — try/except em profundidade
